Ecommerce tracking

A working shop that pushes the six GA4 ecommerce events. You build the tags that catch them.

What makes ecommerce different

Every event so far carried a few loose keys. Ecommerce events carry a strict structure that GA4 recognises by shape, not by name. Get the shape wrong and the event arrives with no products in it — no error, no warning, just empty reports.

dataLayer.push({ ecommerce: null });   // clear the previous product first
dataLayer.push({
  event: 'add_to_cart',
  ecommerce: {
    currency: 'SEK',
    value: 899,
    items: [{
      item_id: 'SKU-101',
      item_name: 'Blue running shoe',
      price: 899,
      quantity: 1
    }]
  }
});

Three rules for this module

  • Everything lives inside one ecommerce object
  • items is always an array, even for one product
  • Push ecommerce: null before every event, or the previous product comes along for the ride

The six events you will see

view_item_listThe product grid appeared. Fires once on load.
select_itemSomeone clicked a product in the list.
add_to_cartA product went into the cart.
remove_from_cartA product came back out.
begin_checkoutCheckout started. The whole cart is in items.
purchaseThe order completed. Needs a transaction_id.
