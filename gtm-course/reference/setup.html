Set up a Tag Manager container

What this page is for

Do this once, before Module 1. It gives you a free container of your own to build in.

You need: a Google account. Nothing else, and no website.

Step 1 Create the account and container

  1. Go to tagmanager.google.com and sign in.

  2. Press Create Account.

  3. Account Nameyour name, or your school
    CountrySweden
    Container namegtm-course
    Target platformWeb

  4. Press Create and accept the terms.

  5. A dialog shows two blocks of code. Close it — you do not need them for this course.

Account and container are not the same thing

An account is usually one company. A container is usually one website. One account can hold many containers. For this course, one of each is plenty.

Step 2 Find your container ID

  1. Look at the top right of the workspace, next to the Preview button.

  2. You will see something like GTM-A1B2C3D. That is your container ID.

  3. Copy it.

Three IDs that look alike

  • GTM-XXXXXXX — a Tag Manager container. This is the one you want.
  • G-XXXXXXXXXX — a GA4 measurement ID. Used inside a tag, not instead of the container.
  • AW-XXXXXXXXX — a Google Ads conversion ID.

Step 3 Connect it to this course

Three ways. The first is permanent, the other two are for a quick test.

  1. Edit one file. Open assets/config.js in this folder and put your ID between the quotes:

    window.GTM_COURSE_CONFIG = {
  containerId: 'GTM-A1B2C3D',
  hideConnectBox: false
};

    Save, upload, done. Every page in the course now loads your container.

  2. Or paste it into the box under the dataLayer panel on any page and press Connect. It is remembered in your browser for every other page.

  3. Or add it to the address: ?gtm=GTM-A1B2C3D. Quickest way to hand a container to a whole classroom at once.

Check that the panel's status line turns green and names your container.

Step 4 Check that Preview works

  1. Press Preview at the top right of Tag Manager.

  2. Paste this page's address into Tag Assistant and press Connect.

  3. A new tab opens with this page and a "Tag Assistant Connected" badge.

  4. Switch back to Tag Assistant. You should see a Container Loaded event.

What you should see

  • The panel on this page shows a green dot and your container ID.
  • Tag Assistant connects and lists events in the left column.
  • You are ready for exercise 1.1.

If it does not work

  • Tag Assistant will not connect. An ad blocker or a browser blocking third-party cookies. Try an incognito window with extensions disabled.
  • The panel stays grey. The ID was mistyped, or a network filter is blocking googletagmanager.com. Check the browser console for a blocked request.
  • You are in the wrong container. The container name is next to the ID at the top. Switch with the account picker.

Publishing, for when you need it

Preview shows changes to you alone. To make them real for everyone:

  1. Press Submit at the top right.

  2. Give the version a name that says what changed — Added click tracking on CTA, not v2.

  3. Press Publish.

Every publish creates a version you can roll back to from Versions. This is the safety net that makes Tag Manager worth using.

Putting this folder on your own website

Unzip the folder and upload it to your GitHub Pages repository — as a folder called gtm-course at the top level. It then lives at https://yourname.github.io/gtm-course/.

  1. Unzip gtm-course.zip.

  2. Edit assets/config.js and put your container ID in it.

  3. Drag the whole gtm-course folder into your repository on github.com, or commit it from your editor.

  4. Wait a minute, then open https://yourname.github.io/gtm-course/.

Two container snippets on one page

Your own site already has the Tag Manager snippet in its template. These course pages are standalone HTML and do not inherit it — which is why config.js exists.

If you ever paste the snippet into these pages as well, the container loads twice and every tag fires twice. Use one method, not both.

Opening the files without uploading

Double-clicking the HTML files works for almost everything. Two exceptions, both because the browser treats file:// as untrusted: the hashing in exercise 2.2 needs HTTPS, and the container ID is not remembered between pages. Upload to GitHub Pages and both work.

The snippet, for reference

This is what your own website already has in its template. You do not need to add it to these pages:

<!-- Google Tag Manager — as high in <head> as possible -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXXX');</script>

<!-- immediately after the opening <body> tag -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-XXXXXXX"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>

Replace both GTM-XXXXXXX with your own ID. It must go on every page, which is why it belongs in a template rather than pasted page by page.
