Module 3 Six exercises About an hour

URL parameters

What this module is for

Everything after the question mark in a URL. It is where campaign data lives and where the most avoidable tracking mistakes get made.

Six exercises. Reading a parameter is trivial; the exercises are about what goes wrong afterwards.

How to read a URL

https://example.com/shoes?product=runner&color=blue#reviews
└──────────────────────┘ └─────────────────────────────┘ └──────┘
        page                    query parameters          fragment
  • ? starts the query, & separates parameters. Order does not matter.
  • The fragment after # is never sent to the server. Useless for campaigns.
  • Parameter names are case sensitive.
