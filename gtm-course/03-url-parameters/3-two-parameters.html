3.3 Getting real 25 minutes

Combine two parameters

What this page is for

This is a product page that takes its product and colour from the URL and pushes both as one nested object. You will read into that object from Tag Manager.

You will build:

  • Two URL Variables
  • Two Data Layer Variables using dot notation
  • A tag that shows both sources agreeing

Step 1 Load a few combinations

Product page

Laptop, Silver Laptop, Space Grey Headphones, Black Headphones, no colour Neither

What the page pushes

dataLayer.push({
  event: 'product_view',
  product_info: {                  // one object, replaced whole every time
    name:  'Laptop',
    color: 'Silver'
  }
});

The flat alternative would be product_name and product_color side by side at the top level. Both work. Nesting is better for one reason: when the next product view pushes a product_info with no colour, the whole object is replaced and the old colour goes with it. Flat keys persist individually — and you end up reporting a silver pair of headphones.

Step 2 Build two URL Variables

url — productURL, Query, key product, default (not set)
url — colorURL, Query, key color, default (not set)

Step 3 Build two Data Layer Variables with dots

dlv — product_info.nameData Layer Variable Name: product_info.name
dlv — product_info.colorData Layer Variable Name: product_info.color

The dot is not a Tag Manager feature you switch on. It is a path into an object, and works to any depth: a.b.c.d. For an array, use the index: items.0.item_name.

Step 4 Build the trigger and tag

  1. Triggers › New › Custom Event, event name product_view.

  2. Tags › New › Custom HTML:

    <script>
  console.log("Viewing", {{dlv — product_info.name}},
              "in", {{dlv — product_info.color}},
              "| URL says", {{url — product}});
</script>

  3. Attach the trigger. Save. Preview and click through the links above.

What you should see

  • With ?product=Laptop&color=Silver: both pairs of variables show Laptop and Silver.
  • The URL variables and the dataLayer variables always agree on this page. They come from different places — the address bar and an object the page built.
  • With ?product=Headphones and no colour: dlv — product_info.color shows (not set), because the page pushed a fresh object without that key.

If it does not work

  • The nested variable is empty. Look at the actual object in the panel first. If a developer literally named a key "product.name" instead of nesting, dot notation will look for an object and find nothing.
  • Space Grey arrives broken. Spaces must travel as %20. Browsers do this when you type; code has to be told, with encodeURIComponent(). An & inside a value splits the parameter in half.
  • ?color=red&color=blue only gives you red. Repeated parameters are legal. The URL variable returns the first and silently drops the rest.

Go further

  1. Add a third parameter ?size= all the way through: URL variable, pushed object, Data Layer Variable, tag.
  2. Build a Custom JavaScript variable that joins the values into a SKU like laptop-silver-15 — lowercased, spaces turned into hyphens.
  3. Change the page's push to flat keys instead of a nested object. Load Laptop/Silver, then Headphones with no colour. Watch the bug appear.
