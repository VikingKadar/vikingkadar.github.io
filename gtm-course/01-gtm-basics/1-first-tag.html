1.1 Beginner 20 minutes

Install a container and fire your first tag

What this page is for

This page is a practice website. You attach your own Tag Manager container to it, then make one tag run on it.

You will build:

  • A Custom HTML tag that writes a message to the browser console
  • An All Pages trigger that runs it on every page load
  • A working Preview session in Tag Assistant

Before you start

  • You need a container ID. It looks like GTM-A1B2C3D.
  • No container yet? Do Set up a container first. It takes 10 minutes.

Step 1 Attach your container to this page

  1. Copy your container ID from the top right of the Tag Manager workspace.

  2. Paste it into the box under the dataLayer panel on this page.

  3. Press Connect. The page reloads.

  4. Check the panel. The status line should now name your container.

What you just skipped

On a real website you paste two blocks of code into the HTML instead: a <script> in the <head> and a <noscript> just after <body>. Tag Manager shows both under Admin › Install Google Tag Manager. This page does it for you so you can start building today.

Step 2 Build the tag

  1. In Tag Manager, go to Tags › New.

  2. Click the Tag Configuration box. Choose Custom HTML.

  3. Paste this into the HTML field:

    <script>
  console.log("My first tag fired.");
</script>

  4. Click the Triggering box. Choose All Pages.

  5. Name the tag HTML — hello world at the top left.

  6. Press Save.

Step 3 Test it in Preview

  1. Press Preview at the top right of Tag Manager.

  2. Tag Assistant opens in a new tab and asks for a URL. Paste this page's address.

  3. Press Connect. A second tab opens with this page in it.

  4. Switch back to the Tag Assistant tab.

  5. Click Container Loaded in the left column.

What you should see

  • The dataLayer panel on this page names your container and shows a green dot.
  • Tag Assistant lists your tag under Tags Fired on the Container Loaded event.
  • The browser console prints My first tag fired. Open it with F12, or right-click the page, choose Inspect, then the Console tab.

Or check automatically

This button reads the page and reports what it can see.

Press the button.

If it does not work

  • Tag Assistant will not connect. Turn off your ad blocker. Try an incognito window.
  • The tag is under Tags Not Fired. The trigger is missing or wrong. Reopen the tag and check that All Pages is attached.
  • Nothing in the console. Make sure you are looking at the tab with this page in it, not the Tag Assistant tab.
  • The panel says no container. The ID was mistyped. It must start with GTM-, not G- or AW-.

Preview is not published

Your tag runs for you only. Tag Assistant set a cookie in your browser that tells the container to use your unsaved workspace. Everyone else still gets the last published version.

To make it real: Submit, then Publish.

Go further

  1. Change the message and preview again. You do not need to publish to test a change.
  2. Add a second tag on the same All Pages trigger. Confirm both fire.
  3. Press Submit and Publish. Open this page in a different browser and check the console.
