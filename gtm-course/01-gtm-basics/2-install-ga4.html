Install Google Analytics 4

What this page is for

Right now your container fires tags that write to the console. Nothing is being measured anywhere. This exercise connects Google Analytics, so the rest of the course sends data to a real report.

You will build:

  • A GA4 property and a web data stream
  • A Constant variable holding your measurement ID
  • A Google tag on the Initialization — All Pages trigger
  • A verified pageview in DebugView and Realtime

Before you start

  • Finish exercise 1.1 first. You need a working container and Preview mode.
  • Have your Tag Manager workspace open in one tab.

Two different Google products, two different IDs

Tag Manager delivers tags to your site. Its ID looks like GTM-A1B2C3D.

Google Analytics is one of the things Tag Manager delivers. Its ID looks like G-XXXXXXXXXX and is called a measurement ID.

You need both. They are not interchangeable, and mixing them up is the single most common mistake in this exercise.

Step 1 Create a GA4 property

  1. Go to analytics.google.com and sign in.

  2. Press Admin, bottom left.

  3. Press Create › Property.

  4. Fill it in:

    Property nameyour site's name
    Reporting time zoneSweden
    CurrencySwedish Krona (SEK)

    Time zone and currency are awkward to change later. Set them correctly now.

  5. Answer the business questions and press Create.

Step 2 Create a web data stream and copy the measurement ID

  1. When asked to choose a platform, pick Web.

  2. Enter your website URL and give the stream a name.

  3. Press Create stream.

  4. The stream details panel opens. Copy the Measurement ID at the top right. It starts with G-.

  5. Ignore the installation instructions Google offers. You are installing it through Tag Manager.

Step 3 Store the ID as a Constant variable

You could type the ID straight into the tag. Do not. It will end up in five tags, and one day it changes.

  1. In Tag Manager: Variables › User-Defined Variables › New.

  2. Choose Constant.

  3. Valueyour G-XXXXXXXXXX
    Nameconst — GA4 measurement ID

  4. Save. This is your first genuinely useful variable.

Step 4 Build the Google tag

  1. Tags › New.

  2. Click Tag Configuration and choose Google Tag.

  3. Tag ID{{const — GA4 measurement ID}}
    Configuration settingsleave empty for now
    TriggerInitialization — All Pages
    NameGA4 — Google tag

  4. Save.

Initialization, not All Pages

There are two triggers with almost the same name. Initialization — All Pages fires before everything else in the container.

Google Analytics has to load before any GA4 event tag fires, or the events arrive with nothing to attach to. Use Initialization for this tag and All Pages for everything else.

Step 5 Verify it in DebugView

  1. Press Preview in Tag Manager and connect to this page.

  2. Click around the demo below so there is something to look at.

  3. In Google Analytics, go to Admin › DebugView.

  4. Watch the middle column. Events appear within a few seconds.

Something to click while you watch

These push events to the dataLayer. In exercise 1.3 you will turn them into GA4 events.

Press a button.

What you should see

  • Tag Assistant lists GA4 — Google tag under Tags Fired on the Initialization event.
  • DebugView shows a device connected, with page_view, session_start and first_visit events.
  • Clicking an event in DebugView opens its parameters — page_location, page_title, language and more, all collected automatically.
  • Reports › Realtime shows 1 user in the last 30 minutes.

If it does not work

  • DebugView is empty. It only shows traffic from a browser in debug mode. Tag Manager's Preview turns that on for you — so you must be in Preview, in the tab Tag Assistant opened.
  • The tag fires but no data arrives. An ad blocker or tracking protection is blocking google-analytics.com. Test in an incognito window with extensions off.
  • Your variable is empty. Constants have no default. Reopen it and check the value was actually saved.
  • You pasted the GTM ID into the tag. The Google tag needs G-, not GTM-. It will fail silently.
  • Realtime is empty but DebugView works. Give it a minute. Standard reports take up to 24 hours; Realtime and DebugView are the only instant views.

What you get for free

The Google tag alone gives you page_view, session_start, first_visit, scroll, click on outbound links, file_download and site search. Google calls these enhanced measurement, and they are switched on in the data stream settings.

Everything you build in the rest of this course is what enhanced measurement cannot do for you.

Go further

  1. Open the data stream settings and look at the enhanced measurement toggles. Turn off Scroll, since you will build your own in exercise 1.6.
  2. Press Submit and Publish, then visit this page in a normal window and check Realtime.
  3. Find where in Admin you set data retention, and set it to 14 months.
  4. Note what GA4 is doing without consent from the visitor. That is a real problem for a European site, and worth raising with your teacher.
