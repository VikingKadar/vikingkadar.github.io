1.3 Beginner 35 minutes

Track a button click, and send it to GA4

What this page is for

This page has four things you can click. You will make a tag fire on one of them and stay quiet on the other three.

You will build:

  • The built-in click variables, switched on
  • An All Elements trigger filtered to one button
  • A Custom HTML tag that logs which button was clicked
  • A real GA4 event tag that sends the same click to Google Analytics

Step 1 Click the demo buttons

Click each one. The box underneath shows what Tag Manager sees. Note how the values differ — that difference is what you will filter on.

Step 2 Switch on the click variables

  1. Go to Variables in the left menu.

  2. Press Configure in the Built-In Variables section.

  3. Scroll to Clicks and tick all five:

    • Click Element
    • Click Classes
    • Click ID
    • Click Text
    • Click URL

  4. Close the panel. You do this once per container.

Do not skip this step

Until these are ticked, the trigger condition dropdown will not offer them and nothing you build will fire. This is the most common reason a beginner's click trigger does nothing.

Step 3 Build the trigger

  1. Go to Triggers › New.

  2. Choose Click › All Elements.

  3. Select Some Clicks.

  4. Set the condition and name:

    Trigger typeClick — All Elements
    Fires onSome Clicks
    ConditionClick ID  equals  signup-btn
    NameClick — Start free trial button

  5. Save.

Step 4 Build the tag

  1. Go to Tags › New › Custom HTML.

  2. Paste this in. Type {{ in Tag Manager and it will autocomplete the variable names.

    <script>
  console.log("Clicked:", {{Click Text}}, {{Click ID}});
</script>

  3. Attach the trigger you just made.

  4. Name it HTML — click logger and save.

  5. Press Preview, connect to this page, and click all four demo elements.

Step 5 Send the click to GA4 for real

The console tag proved the trigger works. Now replace it with something that measures.

  1. Tags › New and choose Google Analytics: GA4 Event.

  2. Measurement ID{{const — GA4 measurement ID}}
    Event Namecta_click
    TriggerClick — Start free trial button
    NameGA4 — cta_click

  3. Open Event Parameters and add two rows. This is where your variables earn their keep:

    button_text{{Click Text}}
    button_id{{Click ID}}

  4. Save. Press Preview and click Start free trial.

  5. Open Admin › DebugView in Google Analytics and click the cta_click event to see your two parameters.

Event names are a decision, not a detail

Use lowercase with underscores: cta_click, not CTA Click. Use the same name for the same thing everywhere on the site, and put the differences in parameters instead. One cta_click event with a button_text parameter beats fourteen event names.

What you should see

  • Tag Assistant shows a Click event for every one of your four clicks. This is correct — the trigger listens to all clicks, then filters.
  • Only the Start free trial click has your tag under Tags Fired. The other three have it under Tags Not Fired.
  • The console prints Clicked: Start free trial signup-btn once.
  • Clicking that event and opening the Variables tab shows Click ID as signup-btn.
  • DebugView shows a cta_click event carrying button_text and button_id.

If it does not work

  • No Click events appear at all. The built-in click variables are not enabled. Go back to Step 2.
  • Click ID is empty. You clicked text inside the button, not the button. Change the condition to Click Element matches CSS selector #signup-btn, #signup-btn *.
  • The tag fires on several buttons. You used contains where you needed equals, or filtered on Click Classes instead of Click ID.
  • The GA4 event never reaches DebugView. The Google tag from exercise 1.2 is missing, or it is on All Pages instead of Initialization — All Pages, so it loads after your event tag.
  • Nothing fires on the link. Links need either All Elements or the Just Links trigger type. Just Links also gives you Click URL and a Wait for Tags option.

Click Classes is one long string

It is every class on the element, separated by spaces, in the order written in the HTML. Use contains on it, never equals. contains cta would match the first two buttons above.

Go further

  1. Make a trigger that fires on both call-to-action buttons using Click Classes contains cta. Confirm Contact sales does not fire it.
  2. Make a Just Links trigger for the link and log {{Click URL}}.
  3. Make one GA4 event tag that fires for any element whose Click Classes contains btn, sending {{Click Text}} as a parameter. One tag for every button is how this is done on a real site.
  4. In GA4, go to Admin › Events after a day and find your cta_click. Mark it as a key event.
