Tags, triggers and variables

What this module is for

Everything Tag Manager does is three nouns: a tag runs, a trigger decides when, a variable fills in the details.

Start here. Do the exercises in order.

Before you start

  • Get a free container: Set up a container, 15 minutes
  • Paste your container ID into the box under the panel on any exercise page
  • Every page then loads your container, so your tags fire on these demos

Console tags first, GA4 tags second

Most exercises here start with a Custom HTML tag that writes to the browser console. It proves the trigger works in seconds, with no waiting for a report to update.

Google Analytics goes in at exercise 1.2. From there you can swap any console tag for a real GA4 event tag — exercise 1.3 walks through that swap, and the rest are yours to convert.
