Learn Google Tag Manager by building it

Twenty practice pages built to be tracked. Each one tells you what it is for, what to build in Tag Manager step by step, and exactly what you should see when it works.

How to use this course

  1. Get a free container: Set up a container. 15 minutes.

  2. Paste your container ID into the box under the panel on the right.

  3. Start at exercise 1.1 and work down.

Why every page has that black panel

You cannot see the dataLayer. It is the most important object on the page and it is invisible, which is the hardest part of starting with Tag Manager. So every page in this course puts it on screen. Press a button and watch.

Try it now

No container needed. The dataLayer is a plain JavaScript array that any page can have.

Attaching your own container

No copying files, no writing code. Two ways:

  • Paste the ID into the box under the dataLayer panel on any page
  • Or add ?gtm=GTM-XXXXXXX to the address — the quickest way to hand a container to a whole class

Every page then loads your container, so your tags fire on these demos and appear in your own Preview mode.
