The dataLayer

What this module is for

The dataLayer is a JavaScript array a website uses to tell Tag Manager things. It is the difference between guessing what happened and being told.

Do Module 1 first. These exercises assume you can build a trigger and a tag.

The entire API

window.dataLayer = window.dataLayer || [];

window.dataLayer.push({
  event: 'add_to_cart',
  product_name: 'Blue running shoe',
  value: 899
});
  • Line 1 creates the array if the container script has not already. Script order can then never break it.
  • event is the special key. Tag Manager watches for it and wakes up.
  • Every other key is data, waiting for you to name it in a Data Layer Variable.

Three rules to memorise

Push before you need it A tag can only read what is already in the dataLayer when it fires.
The dataLayer remembers Values persist across later events until something overwrites them. Exercise 2.1 makes you prove it.
Name keys in snake_case product_name, not productName. It matches GA4 and everyone guesses the same spelling.
