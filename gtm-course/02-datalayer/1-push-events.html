2.1 Getting real 30 minutes

Push your own events

What this page is for

The buttons on this page push events into the dataLayer, the way a developer would. You will catch one of them in Tag Manager, then deliberately break it.

You will build:

  • A Custom Event trigger
  • Two Data Layer Variables for the event's payload
  • A reproduction of the stale-value bug that catches everyone once

Step 1 Press the buttons and read the panel

Press them left to right, top row first. Each entry in the panel is exactly what the button sent.

Buttons that push

Nothing pushed yet.

What each button sends

// cta_click
{ event: 'cta_click', button_text: 'cta_click', page_section: 'demo' }

// video_start
{ event: 'video_start', video_title: 'How the dataLayer works', video_duration: 312 }

// newsletter_signup — note: no video_title
{ event: 'newsletter_signup', method: 'footer form' }

Step 2 Build the Custom Event trigger

  1. Triggers › New › Custom Event.

  2. Event namevideo_start
    Use regex matchingOff
    Fires onAll Custom Events
    NameCustom Event — video_start

  3. Save. The event name must match the push character for character, including case.

Step 3 Build two Data Layer Variables

  1. Variables › New › Data Layer Variable. Name: dlv — video_title, Data Layer Variable Name: video_title.

  2. Repeat for dlv — video_duration / video_duration.

  3. Give both a Default Value of (not set).

Step 4 Build the tag and test

  1. Tags › New › Custom HTML:

    <script>
  console.log("Video started:", {{dlv — video_title}},
              "length", {{dlv — video_duration}});
</script>

  2. Attach the Custom Event — video_start trigger. Save.

  3. Press Preview, connect to this page, press video_start.

Step 5 Break it on purpose

  1. Build a second Custom Event trigger for newsletter_signup.

  2. Build a second tag on it that logs {{dlv — video_title}} — a variable that has nothing to do with newsletters.

  3. Press video_start, then press newsletter_signup.

  4. Read the console.

What you should see

  • A video_start event in Tag Assistant with your first tag under Tags Fired.
  • On that event, Variables shows How the dataLayer works and 312.
  • After pressing newsletter_signup: your second tag logs How the dataLayer works — a video title, on a newsletter event.
  • The newsletter_signup push in the panel contains no video_title at all.

Why that happened

The dataLayer is cumulative. Tag Manager keeps a running model of every key it has ever seen, and a key keeps its last value until something replaces it. This is why you get purchases attributed to the wrong product.

Two fixes:

  • Push video_title: undefined before the next unrelated event. That is what the Clear video_title button does.
  • Better: nest related data under one object per event, so the whole object is replaced at once. That is exactly why GA4 ecommerce data lives inside an ecommerce object.

If it does not work

  • The trigger never fires. The event name does not match. Copy it from the panel rather than typing it.
  • The variable is empty. The Data Layer Variable Name must be the key, not the event name. It is video_title, not video_start.
  • Pressing "Push data with no event key" fires nothing. Correct. An object with no event key updates variables but triggers no tags. That is useful for setting data up in advance.

Go further

  1. Make one trigger that catches all three events using Use regex matching with cta_click|video_start|newsletter_signup, and one tag that logs the built-in {{Event}} variable.
  2. Press Push data with no event key, then newsletter_signup. Does your tag see the user_type value? Explain why to the person next to you.
  3. Replace the Custom HTML tag with a real GA4 event tag named video_start, with video_title and video_duration as event parameters.
