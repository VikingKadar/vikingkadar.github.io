Track clicks and a form

What you will do

When a visitor clicks one of the big buttons on the home page, or sends the subscribe form, the shop puts an event in the dataLayer. An event is an entry with a name, and with information about what happened. You will catch two events and send them to Google Analytics with that information.

You will build two triggers, six variables and two tags.

Step 1 Look at the two events

  1. Open the shop's home page. Scroll to the bottom and open Developer view.

  2. Scroll back up and click the orange button Start your subscription. A new entry appears in the Developer view for a moment before the page changes. It looks like this:

    {
  event: 'cta_click',
  cta: {
    text: 'Start your subscription',
    location: 'hero',
    destination: 'signup.html'
  }
}

    The event is called cta_click. CTA means call to action, the name marketers use for a button that asks you to do something. The information about the click is inside cta.

  3. You are now on the Subscribe page. Choose Every week, tick the box about email, and click Subscribe. Open the Developer view. The new entry looks like this:

    {
  event: 'generate_lead',
  lead: {
    plan: 'weekly',
    bag_size: '250g',
    source: 'signup_page',
    value: 516
  },
  user: {
    consent: { marketing: true }
  }
}

Step 2 Build two triggers

A Custom Event trigger fires when an event with a certain name appears in the dataLayer.

  1. In Tag Manager, click Triggers, then New. Click Trigger Configuration and choose Custom Event.

  2. In the field Event name, type cta_click. Name the trigger CE - cta_click. Click Save.

  3. Make a second one the same way. Event name generate_lead, trigger name CE - generate_lead.

Step 3 Build six variables

Make six Data Layer Variables, the same way as in exercise 2. Version 2 every time.

Name of the variableData Layer Variable Name
dlv - cta.textcta.text
dlv - cta.locationcta.location
dlv - cta.destinationcta.destination
dlv - lead.planlead.plan
dlv - lead.bag_sizelead.bag_size
dlv - lead.valuelead.value

Step 4 Build two tags

  1. Click Tags, then New. Choose Google Analytics: GA4 Event. Fill it in like this:

    Measurement IDYour G- ID
    Event Namecta_click
    Event Parameterscta_text = dlv - cta.text
    cta_location = dlv - cta.location
    cta_destination = dlv - cta.destination
    TriggeringCE - cta_click
    NameGA4 - cta_click

    Remember: for each parameter, the left field is typed, and the right field is chosen with the building-block icon.

  2. Make a second tag:

    Measurement IDYour G- ID
    Event Namegenerate_lead
    Event Parametersplan = dlv - lead.plan
    bag_size = dlv - lead.bag_size
    value = dlv - lead.value
    currency = type SEK
    marketing_consent = dlv - user.consent.marketing
    TriggeringCE - generate_lead
    NameGA4 - generate_lead

    generate_lead is a name Google Analytics already knows. Because you send value and currency with it, Google Analytics can count it as a conversion worth 516 kr.

Step 5 Test it

  1. Click Preview, enter the address of the shop's home page, and click Connect.

  2. In the shop window, click Start your subscription. Then fill in the subscribe form and click Subscribe.

  3. In Tag Assistant, look at the list on the left. Under the home page there is an event called cta_click. Click it. Under Tags Fired is GA4 - cta_click. Click the tag to see the three parameters.

  4. Under the subscribe page there is an event called generate_lead. Click it. GA4 - generate_lead has fired with five parameters.

  5. Open DebugView in Google Analytics and check that both events arrived.

Step 6 See how the dataLayer remembers

  1. In the shop window, click Log in (demo) at the top right. It is a pretend login. Then open the Subscribe page and send the form again.

  2. In Tag Assistant, click the new generate_lead event, then the tab Data Layer.

  3. Look at user. The form only sent user.consent.marketing. But user.id and user.tier are also there, from the page information. Tag Manager remembers earlier values and only replaces the ones that were sent again.

Why this matters

Tag Manager keeps one running copy of the dataLayer. New information is merged into it. This is useful for user, because the login is remembered. It is dangerous for a shopping cart, because the products from the last event would still be there. In the next exercise you will see what the shop does about that.

If it does not work

  • I cannot find cta_click in Tag Assistant. It is under the home page in the list on the left, not under the subscribe page. The click happened before the page changed.
  • A parameter is empty. Open the variable and check the Data Layer Variable Name. It is cta.location with a dot, not cta_location.
If you get stuck, search for: gtm custom event trigger, ga4 generate_lead event.
