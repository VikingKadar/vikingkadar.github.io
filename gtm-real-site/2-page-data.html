Exercise 2 Getting real About 45 minutes

Read information the shop puts in the dataLayer

What you will do

Every page of the shop tells Tag Manager what kind of page it is, and whether the visitor is logged in. It does this by putting a small package of information in the dataLayer. In this exercise you will read that information, use it to decide when a tag runs, and send it to Google Analytics.

You will build three things: variables that read the information, a trigger that only fires on product pages, and a tag that sends an event to Google Analytics.

Step 1 Look at what the shop sends

  1. Open the All coffees page of the shop, online, at your own address.

  2. Scroll to the bottom and click Developer view. The panel shows every entry in the dataLayer, oldest first.

  3. Look at the entry marked [1]. It is the package the shop sends on every page.

The package has two parts. page says what kind of page this is. user says who is looking at it. Each part has smaller parts inside it. For example, inside user there is consent, and inside consent there is marketing. To point at that value you write the names with dots between them: user.consent.marketing.

Step 2 Build four variables

A Data Layer Variable is a variable that reads one value from the dataLayer. You will build four.

  1. In Tag Manager, click Variables in the menu on the left.

  2. Scroll down to the section User-Defined Variables and click New.

  3. Click the big box Variable Configuration. Choose Data Layer Variable.

  4. In the field Data Layer Variable Name, type page.type.

  5. Check that Data Layer Version says Version 2. If it says Version 1, change it. Version 1 does not understand the dots.

  6. At the top left, where it says Untitled Variable, type the name dlv - page.type. Click Save.

  7. Repeat steps 2 to 6 three more times with these values:

    Name of the variableData Layer Variable Name
    dlv - page.categorypage.category
    dlv - user.tieruser.tier
    dlv - user.consent.marketinguser.consent.marketing

Step 3 Check the variables in Preview mode

  1. Click Preview at the top right of Tag Manager. Enter the address of the shop's All coffees page and click Connect.

  2. In the Tag Assistant tab, click Container Loaded in the list on the left.

  3. In the middle of the page there are tabs: Tags, Variables, Data Layer. Click Variables.

  4. Scroll down the list until you find your four variables. dlv - page.type should have the value listing.

  5. Go to the shop window and click on one of the coffees. Go back to Tag Assistant. Click the new page in the list on the left, then Container Loaded, then Variables. Now dlv - page.type says product.

Step 4 Build a trigger that only fires on product pages

  1. In Tag Manager, click Triggers in the menu on the left. Click New.

  2. Click the big box Trigger Configuration. Choose Page View.

  3. Under This trigger fires on, choose Some Page Views. Three fields appear.

  4. In the first field, choose dlv - page.type. In the second, choose equals. In the third, type product.

  5. At the top left, type the name PV - product page. Click Save.

Step 5 Build a tag that sends an event to Google Analytics

  1. Click Tags in the menu on the left. Click New.

  2. Click the big box Tag Configuration. Choose Google Analytics: GA4 Event.

  3. In the field Measurement ID, paste your G- ID.

  4. In the field Event Name, type view_product_page.

  5. Click Event Parameters to open it. Click Add parameter. In the left field type page_category. In the right field, click the small icon that looks like a building block and choose dlv - page.category.

  6. Click Add parameter again. Left field: user_tier. Right field: choose dlv - user.tier.

  7. Click the big box Triggering. Choose PV - product page.

  8. At the top left, type the name GA4 - view_product_page. Click Save.

Step 6 Test it

  1. Go to the shop window. It is still connected to Preview mode. Open Coffees, then click on a coffee.

  2. In Tag Assistant, click the product page in the list on the left, then Container Loaded. Under Tags Fired you should see GA4 - view_product_page.

  3. Click on the tag. It shows the parameters it sent: page_category is coffee and user_tier is guest.

  4. Now click the All coffees page in the list on the left, then Container Loaded. The tag is under Tags Not Fired. That is correct: it is not a product page.

  5. Go to analytics.google.com. Click Admin (the gear at the bottom left), then DebugView. Go to the shop window and open another coffee. Within a few seconds, view_product_page appears in DebugView. Click it to see the two parameters.

What you should see

  • Four variables with values in the Variables tab in Tag Assistant. The values change from page to page.
  • The tag fires on product pages and not on other pages.
  • In DebugView in Google Analytics, an event called view_product_page with two parameters.

If it does not work

  • A variable has the value undefined. Check for spelling mistakes. Small and capital letters matter: page.type, not Page.Type. Also check that the Data Layer Version is 2.
  • The variable is correct but the trigger never fires. Open the trigger and check that its type is Page View and the condition is exactly dlv - page.type equals product.
  • Nothing appears in DebugView. Check the Measurement ID in the tag. Also try a browser window without extensions, because ad blockers stop Google Analytics.
If you get stuck, search for: gtm data layer variable nested, ga4 debugview.
