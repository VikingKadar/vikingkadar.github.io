Glossary

What this page is for

Every term this course uses, in one line each, with the exercise that teaches it. The names are Google's official ones, so searching for them finds real documentation.

The three nouns

TagThe code that runs. A GA4 event, an advertising pixel, a Custom HTML script.
TriggerThe condition that decides when a tag runs. A tag with no trigger never fires.
VariableA named value filled in at the moment a tag fires. Written {{like this}}.

Containers and publishing

ContainerAll your tags, triggers and variables for one website. Has an ID like GTM-A1B2C3D.
WorkspaceYour unsaved draft. Changes live here until you Submit.
Preview / Tag AssistantRuns your workspace for you alone, and shows what fires.
Submit and PublishMakes the workspace live for everyone. Creates a version you can roll back to.
VersionA saved snapshot of the container. Name them after what changed.

Trigger types

All PagesEvery page load. Ships with every container.
DOM ReadyFires once the page structure is complete. Use it when a tag reads the page.
Click — All ElementsAny click anywhere. Always add a condition.
Click — Just LinksClicks on <a> elements only. Gives you Click URL and Wait for Tags.
Form SubmissionA native form submit. Does nothing on JavaScript forms.
Scroll DepthFires at percentages or pixel depths.
Element VisibilityFires when an element appears on screen. Needs Observe DOM changes for elements added later.
Custom EventFires on an event name pushed to the dataLayer.
History ChangeFires when the URL changes without a page load.
TimerFires after a set interval on the page.

Variable types

ConstantA value you type once and reuse, such as a measurement ID.
Data Layer VariableReads a key from the dataLayer. Use dots for nested values.
DOM ElementReads text or an attribute off the page. Fragile.
URLReads part of the address. Component Type Query reads a parameter.
Lookup TableTranslates one variable's value into another. Case sensitive.
RegEx TableA Lookup Table that matches with regular expressions.
Custom JavaScriptA function that returns a value. Wrap risky reads in try/catch.
Built-In VariablesReady-made variables you switch on under Variables › Configure.

Data

dataLayerA JavaScript array the website uses to tell Tag Manager things.
dataLayer.push()Adds one object to it. The only way data gets in.
event keyThe special key Tag Manager watches. No event, no trigger.
Query parameterA key=value pair after the ? in a URL.
UTM parametersThe five campaign parameters GA4 reads automatically.
sessionStorageBrowser storage that lasts until the tab closes.
SHA-256A one-way fingerprint of a value. What ad platforms accept instead of an email address.

Ecommerce

ecommerce objectThe structured object GA4 recognises by shape.
items arrayThe products. Always an array, even for one product.
ecommerce: nullThe clearing push before every ecommerce event. Skip it and products leak between events.
transaction_idThe order number. GA4 uses it to avoid counting a purchase twice.

Google Analytics 4

Measurement IDIdentifies a GA4 data stream. Looks like G-XXXXXXXXXX.
Google tagThe tag that loads Google Analytics. Belongs on Initialization — All Pages.
GA4 Event tagSends one event to Analytics. Everything you build ends as one of these.
Event parameterExtra detail sent with an event. button_text, value. Prefer parameters over new event names.
DebugViewAdmin › DebugView. Shows your own events within seconds, but only while you are in Preview.
RealtimeReports › Realtime. The last 30 minutes of all traffic. Standard reports take up to 24 hours.
Enhanced measurementEvents GA4 collects on its own once the Google tag is installed: scroll, outbound clicks, file downloads, site search.
Key eventAn event you have marked as important. GA4's word for what used to be called a conversion.
Data streamOne website or app feeding a GA4 property. Where the measurement ID lives.

Google's product IDs

GTM-XXXXXXXA Tag Manager container.
G-XXXXXXXXXXA GA4 measurement ID. Goes inside a tag.
AW-XXXXXXXXXA Google Ads conversion ID.
