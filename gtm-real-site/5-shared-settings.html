Exercise 5 Real work About 45 minutes

Send the same information with every event

What you will do

You now have several tags. Only one of them sends the page type and the user tier. You want that information on every event, without typing it into every tag. Tag Manager has a special variable for that. You will also tell Google Analytics who the logged-in user is, and make your new information visible in Google Analytics reports.

Step 1 Two more variables

  1. Make a Data Layer Variable named dlv - user.logged_in with Data Layer Variable Name user.logged_in.

  2. Make one named dlv - user.id with Data Layer Variable Name user.id. Do not fill in a default value. See the warning at the bottom of this page.

Step 2 The shared settings variable

  1. Click Variables, then New under User-Defined Variables. Click Variable Configuration. Under the heading Google Analytics, choose Google Analytics: GA4 Event Settings.

  2. Under Event Parameters, click Add parameter four times and fill in:

    Left field (typed)Right field (chosen with the icon)
    page_typedlv - page.type
    page_categorydlv - page.category
    user_tierdlv - user.tier
    logged_indlv - user.logged_in

  3. Under Google Analytics User Properties, click Add property. Left field subscription_tier, right field dlv - user.tier. A user property describes the person instead of the event, and Google Analytics keeps it for all their later events.

  4. Name the variable GA4 - shared event settings. Click Save.

Step 3 Use it in every tag

  1. Click Tags. Open GA4 - cta_click. Open Event Parameters. At the top of that section there is a field Event Settings Variable. Choose GA4 - shared event settings. Click Save.

  2. Do the same in GA4 - generate_lead, GA4 - ecommerce, GA4 - order_details and GA4 - view_product_page.

  3. In GA4 - view_product_page, also delete the two parameters page_category and user_tier. The shared variable sends them now.

  4. Open Google tag - GA4. Click Configuration settings to open it. Under Shared event settings, choose GA4 - shared event settings. Now every page view carries the information too. Click Save.

Step 4 Tell Google Analytics who the user is

  1. Still in Google tag - GA4, under Configuration settings, click Add parameter. Left field user_id, right field dlv - user.id. Click Save.

  2. Click Preview and connect to the shop's home page. In the shop, click Log in (demo) at the top right. Then click Coffees.

  3. In Tag Assistant, click the Coffees page, then Container Loaded, then the tag Google tag - GA4. In its details, user_id is u-48213.

  4. In the shop, click Log out, then open another page. Check the same tag again. user_id is now empty. That is what you want for a visitor who is not logged in.

Step 5 Make the information visible in reports

Google Analytics receives every parameter you send, but its reports ignore parameters it has not been told about. This step is done in Google Analytics, and people forget it all the time.

  1. Go to analytics.google.com. Click Admin at the bottom left. Under Data display, click Custom definitions.

  2. Click Create custom dimension. Fill in and save, four times:

    Dimension nameScopeEvent parameter or User property
    Page typeEventpage_type
    User tierEventuser_tier
    CTA locationEventcta_location
    Subscription tierUsersubscription_tier

From now on, new data shows up under these names in the reports. It takes up to a day. DebugView shows it straight away.

What you should see

  • In Tag Assistant, every GA4 tag now lists page_type, page_category, user_tier and logged_in among its parameters.
  • In DebugView, after logging in, a user ID and the user property subscription_tier: member.
  • Four custom dimensions in Google Analytics.

Never give dlv - user.id a default value

If the variable sent a value like "guest" for people who are not logged in, Google Analytics would think all those people are one single person. Leave it empty. And a user ID must always be an internal number, never an email address or a name. Sending those to Google is against Google's rules and against the law in Europe.

If it does not work

  • Some events have the shared parameters and some do not. The tags without them are not using the settings variable yet. Go back to step 3.
  • user_id is empty right after logging in. The Google tag ran when the page loaded, before you logged in. Open another page.
  • A custom dimension shows "(not set)" in reports. The name in Google Analytics must match the parameter name in Tag Manager exactly, including small letters and underscores.
If you get stuck, search for: gtm ga4 event settings variable, ga4 custom dimensions, ga4 user_id gtm.
