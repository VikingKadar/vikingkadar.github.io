Track the shop: products, cart and orders

What you will do

Google Analytics has a fixed set of shop events with fixed names: viewing a list of products, clicking one, viewing it, adding it to the cart, starting checkout, and buying. The shop sends all six. You will catch all of them with one trigger and one tag. That is how it is done on real shops. Then you will read single values from inside the list of products.

Step 1 Walk through the shop and watch

  1. Click Preview in Tag Manager, enter the address of the shop's All coffees page, and connect.

  2. In the shop window, do this in order. After each action, look at the list on the left in Tag Assistant and find the event named in brackets.

    What you doEvent that appears
    Open the All coffees pageview_item_list
    Click the name of a coffeeselect_item
    The coffee's page opensview_item
    Change Bags to 2 and click Add to cartadd_to_cart
    Click Go to checkoutbegin_checkout
    Type FIKA10 as discount code, choose Swish, click Place orderpurchase, then order_details

  3. In Tag Assistant, click add_to_cart, then the tab Data Layer. This is what the shop sent:

    {
  event: 'add_to_cart',
  ecommerce: {
    currency: 'SEK',
    value: 438,
    items: [
      {
        item_id: 'FK-002',
        item_name: 'Slow Sunday',
        item_brand: 'Fika & Co',
        item_category: 'Coffee',
        item_category2: 'Medium roast',
        item_variant: '500 g',
        price: 219,
        quantity: 2
      }
    ]
  }
}

    Everything is inside ecommerce. Inside that, items is a list of products, written with square brackets. Here the list has one product in it. Google Analytics needs exactly this shape.

Step 2 One trigger for all six events

  1. Click Triggers, then New. Choose Custom Event.

  2. In the field Event name, type all six names with a vertical bar between them. The bar means "or":

    view_item_list|select_item|view_item|add_to_cart|begin_checkout|purchase

  3. Tick the box Use regex matching. Without it, Tag Manager would look for an event with that whole long name.

  4. Name the trigger CE - ecommerce events. Click Save.

Step 3 One tag for all six events

  1. Click Tags, then New. Choose Google Analytics: GA4 Event. Paste your G- ID.

  2. In the field Event Name, do not type anything. Click the building-block icon next to the field and choose the variable called Event. The field now shows {{Event}}. This means: use whatever name the event had.

  3. Click More Settings, then Ecommerce. Tick Send Ecommerce data. Under Data source, choose Data Layer.

  4. Click Triggering and choose CE - ecommerce events.

  5. Name the tag GA4 - ecommerce. Click Save.

  6. Walk through the shop again as in step 1. In Tag Assistant, click each of the six events. Under Tags Fired, GA4 - ecommerce is there every time, and each time it sent the event's own name.

  7. Open DebugView in Google Analytics. Click the purchase event. Open Items. Your coffee is there with quantity 2.

Step 4 Read one value from inside the list

Sometimes you need one value from inside the products list, for example to use it in a trigger. The products are numbered from 0. To point at the name of the first product you write ecommerce.items.0.item_name.

  1. Build these Data Layer Variables, Version 2:

    Name of the variableData Layer Variable NameValue on the add_to_cart above
    dlv - ecommerce.valueecommerce.value438
    dlv - ecommerce.items.0.item_nameecommerce.items.0.item_nameSlow Sunday
    dlv - ecommerce.items.0.quantityecommerce.items.0.quantity2
    dlv - ecommerce.couponecommerce.couponempty until purchase

  2. In the shop, add a coffee to the cart. In Tag Assistant, click add_to_cart, then the tab Variables, and find the four variables.

  3. Place an order with the discount code FIKA10. Click purchase, then Variables. Now dlv - ecommerce.coupon says FIKA10.

Step 5 The event after the purchase

Right after purchase, the shop sends one more event, order_details, with facts about the order that do not fit in Google's shop format: how it is delivered and how it was paid.

{
  event: 'order_details',
  order: {
    id: 'FK-583920',
    delivery: { method: 'pickup_point', country: 'SE' },
    payment: { method: 'swish' },
    lines: 1
  }
}

  1. Make a Custom Event trigger with event name order_details. Name it CE - order_details.

  2. Make three Data Layer Variables: order.id, order.delivery.method and order.payment.method. Name them dlv - followed by the same text.

  3. Make a GA4 Event tag. Event Name order_details. Three parameters: transaction_id = dlv - order.id, delivery_method = dlv - order.delivery.method, payment_method = dlv - order.payment.method. Trigger CE - order_details. Name it GA4 - order_details.

  4. Add a coffee to the cart and place another order. In Tag Assistant, both purchase and order_details appear, each with its tag.

What you should see

  • One tag, GA4 - ecommerce, that fires on all six shop events.
  • In DebugView, the purchase event with the products listed under Items.
  • Variables that read a single value from inside the products list.
  • The order_details event in DebugView with delivery and payment method.

Why every shop event is preceded by "ecommerce: null"

Open the Developer view on any shop page. Before each shop event there is an entry with ecommerce: null. That is the shop's code clearing out the old products before it sends new ones. Without it, Tag Manager would remember the products from the last event (you saw this in exercise 3), and a purchase of one coffee could report two. When you work with a real shop, ask the developer to do this.

If it does not work

  • Events arrive in Google Analytics without products. Open the tag and check that Send Ecommerce data is ticked and the data source is Data Layer.
  • Google Analytics shows an event called {{Event}}, with the brackets. You typed it. Delete the text and choose the variable with the building-block icon instead.
  • dlv - ecommerce.items.0.item_name is undefined. Check the spelling. It is items.0. with dots on both sides of the zero.
If you get stuck, search for: ga4 ecommerce events gtm data layer, gtm regex trigger multiple events.
