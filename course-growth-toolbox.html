this site

Every event is my own. Each one has to answer a question I actually have.

This site does not use automatic events only. Each page pushes its own page_meta with a page_type before the GTM container loads, and every click, section view and scroll milestone is pushed to window.dataLayer from assets/site.js. Google Tag Manager picks them up and forwards them to GA4.
